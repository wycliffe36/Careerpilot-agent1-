# CareerPilot Agent - Agents for Humans Hackathon 2026

**Prize:** $40,000 | **Track:** Professional Agents
**Built with:** AWS Strands Agents SDK

### Problem
Job seekers in Kenya spend 4-6 hours per application manually tailoring CVs and cover letters.

### Solution
CareerPilot Agent is an autonomous agent that:
1. Understands job adverts
2. Takes action to tailor CV + cover letter + interview Q&A
3. Helps humans get hired faster
